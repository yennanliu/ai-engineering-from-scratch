# 生成模型 —— 分類與歷史

> 每一個影像模型、文字模型、影片模型、3D 模型，都落在五個桶子裡的某一個。挑錯桶子，你會跟數學纏鬥好幾個星期。挑對了，這個領域過去十二年的進展會在你腦子裡疊得整整齊齊。

**類型：** 學習
**程式語言：** Python
**先修單元：** 階段 2（機器學習基礎）、階段 3（深度學習核心）、階段 7 · 14（Transformer）
**時間：** 約 45 分鐘

## 問題所在

生成模型只做一件事：給定從某個未知分布 `p_data(x)` 取出的訓練樣本，輸出看起來像是同一個分布產生的新樣本。人臉、句子、MIDI 檔、蛋白質結構 —— 眼睛瞇一下，全都是同一個問題。

麻煩在於 `p_data` 活在一個好幾百萬維的空間裡（一張 512x512 的 RGB 影像大約是 786k 維），樣本則落在那個空間裡一層很薄的流形上，而你手上大概只有 1000 萬個範例。硬算密度是沒指望的。每一個生成模型都是一種妥協：拿一個難題去換一個稍微不那麼難的題。

過去十二年活下來的有五個家族。知道每個家族做的是哪一種妥協，你就知道它為什麼在某些任務上贏，又在另一些任務上崩掉。

## 核心概念

![生成模型的五大家族 —— 依「建模對象」分類](../assets/taxonomy.svg)

**1. 顯式密度、可解。** 把 `log p(x)` 寫成一個你真的算得出來的和。自迴歸模型（PixelCNN、WaveNet、GPT）把它分解成 `p(x) = ∏ p(x_i | x_<i)`。正規化流（RealNVP、Glow）則把 `p(x)` 建構成一個簡單基底分布的可逆變換。優點：似然精確、訓練損失乾淨。缺點：自迴歸的推論是序列的（長序列很慢），流需要可逆架構（架構上綁手綁腳）。

**2. 顯式密度、近似。** 從下方界住 `log p(x)`（也就是 ELBO），然後去最佳化這個界。VAE（Kingma，2013）用一個帶變分後驗的編碼器─解碼器。擴散模型（DDPM，Ho，2020）訓練一個去噪器，隱含地最佳化一個加權過的 ELBO。到 2026 年，擴散是影像、影片與 3D 的主流骨幹。

**3. 隱式密度。** 完全跳過密度；學一個生成器 `G(z)` 產出樣本，再學一個判別器 `D(x)` 分辨真假。也就是 GAN（Goodfellow，2014）。推論很快（一次前向傳播），但訓練不穩定是眾所皆知的。就算到了 2026 年，StyleGAN 1/2/3 在固定領域的照片級真實感（人臉、臥室）上仍是最先進的。

**4. 基於分數／連續時間。** 直接學對數密度的梯度 `∇_x log p(x)`（也就是分數）。Song 與 Ermon（2019）證明了分數匹配能把擴散推廣成一個 SDE。流匹配（Lipman，2023）是 2024–2026 年的熱門貨：訓練不需要模擬、路徑更直、取樣比 DDPM 快 4 到 10 倍。Stable Diffusion 3、Flux、AudioCraft 2 全都用流匹配。

**5. 在離散碼上做基於詞元的自迴歸。** 先用 VQ-VAE 或殘差量化器把高維資料壓成一段很短的離散詞元序列，再用一個 Transformer 對這串詞元建模。Parti、MuseNet、AudioLM、VALL-E，還有 Sora 的 patch 分詞器，都是這一套。這其實就是第 1 個桶子再加上一個學出來的分詞器。

## 一段簡史

| 年份 | 模型 | 為什麼重要 |
|------|-------|-----------------|
| 2013 | VAE（Kingma） | 第一個帶有堪用訓練損失的深度生成模型。 |
| 2014 | GAN（Goodfellow） | 隱式密度、沒有似然 —— 樣本卻銳利得驚人。 |
| 2015 | DRAW、PixelCNN | 序列式的影像生成。 |
| 2017 | Glow、RealNVP | 可逆流；有深度而且似然精確。 |
| 2017 | Progressive GAN | 第一次做出百萬像素的人臉。 |
| 2019 | StyleGAN／StyleGAN2 | 照片級真實的人臉；就那個領域至今仍難以超越。 |
| 2020 | DDPM（Ho） | 擴散開始變得實用。 |
| 2021 | CLIP、DALL-E 1、VQGAN | 文字生成影像進入主流。 |
| 2022 | Imagen、Stable Diffusion 1、DALL-E 2 | 潛在擴散 + 文字條件化 = 大宗商品。 |
| 2022 | ControlNet、LoRA | 對預訓練擴散模型的精細控制。 |
| 2023 | SDXL、Midjourney v5、流匹配 | 規模 + 更好的訓練動態。 |
| 2024 | Sora、Stable Diffusion 3、Flux.1 | 影片擴散；流匹配勝出。 |
| 2025 | Veo 2、Kling 1.5、Runway Gen-3、Nano Banana | 生產級的影片。 |
| 2026 | Consistency + Rectified Flow | 從擴散骨幹做到單步取樣。 |

## 五問快篩

有新的生成模型論文丟出來時，在讀方法章節之前先回答這五個問題。

1. **建模的對象是什麼？** 像素、潛在向量、離散詞元、3D 高斯、網格、波形？
2. **密度是顯式還是隱式？** 他們有把 `log p(x)` 寫下來嗎？
3. **取樣是一次到底還是迭代？** 迭代意味著推論比較慢；一次到底通常代表用了對抗訓練或蒸餾。
4. **條件是什麼：無條件、類別、文字、影像、姿態？** 這決定了損失與架構的鷹架。
5. **評估用什麼：FID、CLIP score、IS、人類偏好、任務準確率？** 每一種都有已知的失效模式（見第 14 單元）。

這個階段的每一個單元，你都會把這五題再答一次。到最後，它們會變成反射動作。

## 動手實作

本單元的程式碼是一個輕量的視覺化：用三種玩具做法，從樣本去擬合一個 1 維的高斯混合（核密度、離散直方圖，以及一個取最近樣本的「類 GAN」生成器），讓你在一個螢幕就印得完的問題上，看清顯式密度與隱式密度的差別。

執行 `code/main.py`。它會從一個雙峰高斯混合抽 2000 個樣本，然後印出：

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前兩者讓你能問「這個點的機率有多高？」第三者不能。這就是*顯式與隱式*的分野，接下來每一個單元都會用到它。

## 框架應用

2026 年，什麼任務該用哪個家族？

| 任務 | 最佳家族 | 為什麼 |
|------|-------------|-----|
| 照片級人臉、領域很窄 | StyleGAN 2/3 | 依然最銳利、推論最快。 |
| 一般的文字生成影像 | 潛在擴散 + 流匹配 | SD3、Flux.1、DALL-E 3。 |
| 快速的文字生成影像 | Rectified flow + 蒸餾 | SDXL-Turbo、SD3-Turbo、LCM。 |
| 文字生成影片 | Diffusion Transformer + 流匹配 | Sora、Veo 2、Kling。 |
| 語音與音樂 | 基於詞元的自迴歸（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 離散詞元擴展起來很便宜。 |
| 3D 場景 | Gaussian Splatting 擬合、擴散先驗 | 重建用 3D-GS，新視角用擴散。 |
| 密度估計（不取樣） | 流 | 唯一有精確 `log p(x)` 的家族。 |
| 模擬／物理 | 流匹配、score SDE | 直線路徑、平滑的向量場。 |

## 關鍵術語

| 術語 | 大家怎麼說 | 實際上是什麼 |
|------|-----------------|-----------------------|
| 生成模型 | 「它會生出新東西」 | 學一個 `p_data(x)` 的取樣器，有時額外提供 `log p(x)`。 |
| 顯式密度 | 「你算得出來」 | 模型提供閉式或可解的 `log p(x)`。 |
| 隱式密度 | 「GAN 那一派」 | 只有取樣器 —— 沒辦法對給定的點算出 `p(x)`。 |
| ELBO | 「證據下界」 | `log p(x)` 的一個可解下界；VAE 與擴散都在最佳化它。 |
| 分數 | 「對數密度的梯度」 | `∇_x log p(x)`；擴散與 SDE 模型學的就是這個場。 |
| 流形假設 | 「資料活在一個曲面上」 | 高維資料集中在一個低維流形上；這就是降維為什麼有用。 |
| 自迴歸 | 「預測下一塊」 | 把聯合分布分解成條件機率的乘積。 |
| 潛在向量 | 「壓縮後的碼」 | 低維表示，解碼器可以由它重建輸入。 |

## 生產環境註記：五個家族，五種推論形狀

每個家族對應到一條不同的推論伺服器成本曲線。生產推論的文獻把 LLM 推論拆成預填（prefill）+ 解碼（decode）；同樣的拆法在這裡也適用：

- **自迴歸（桶子 1 與 5）。** 序列式解碼主導延遲；KV 快取、連續批次與推測式解碼全都能直接套用。
- **VAE／擴散／流匹配（桶子 2 與 4）。** 沒有 LLM 意義下的解碼階段。成本 = `num_steps × step_cost`，而 `step_cost` 是一次在完整潛在解析度上跑的 transformer 或 U-Net 前向傳播。生產環境的旋鈕是步數（DDIM／DPM-Solver／蒸餾）、批次大小與精度（bf16／fp8／int4）。
- **GAN（桶子 3）。** 一次前向傳播。沒有排程、沒有 KV 快取。TTFT ≈ 總延遲。這就是 StyleGAN 在窄領域的使用體驗上還贏的原因。

當你在論文摘要看到「比擴散更快」，把它翻譯成「步數更少 × 同樣的單步成本」或「同樣的步數 × 更便宜的單步成本」。其餘都是行銷。
