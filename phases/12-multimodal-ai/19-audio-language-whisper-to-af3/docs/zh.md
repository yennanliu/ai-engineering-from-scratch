# 音訊—語言模型：從 Whisper 到 Audio Flamingo 3 這條弧線

> Whisper（Radford 等人，2022 年 12 月）把語音辨識這件事定了下來 —— 68 萬小時的弱監督多語言語音、一個簡單的編碼器—解碼器 Transformer，以及一個讓後續每次 ASR 發表都得引用它的基準。但辨識不等於推理。要問「這段錄音裡有哪些樂器」、「說話者表達的是什麼情緒」或「第 3 分鐘發生了什麼」，需要的是音訊理解，不是轉錄。Qwen-Audio、SALMONN、LTU 與 NVIDIA 的 Audio Flamingo 3（AF3，2025 年 7 月）逐步把這套堆疊建了起來：保留 Whisper 等級的編碼器、接上 Q-former、在音訊—文字指令資料上訓練，再加上思維鏈推理。這一課會走一遍這條弧線。

**類型：** 實作
**程式語言：** Python (stdlib, log-Mel spectrogram + audio Q-former skeleton)
**先修單元：** 階段 6（語音與音訊）、階段 12 · 03（Q-Former）
**時間：** 約 180 分鐘

## 學習目標

- 從波形算出對數梅爾頻譜圖：加窗、FFT、濾波器組、對數變換。
- 比較各種編碼器選項：Whisper 編碼器、BEATs、AF-Whisper 混合體。各自在什麼時候勝出。
- 做一個音訊 Q-former：N 個可學習 query 去交叉關注頻譜圖的 patch。
- 說明串接式（先 Whisper 再 LLM）與端到端音訊 LLM 訓練的差別：為什麼端到端在推理上擴展得更好。

## 問題所在

語音辨識已被 Whisper 解決。音訊版的 OCR 已是大宗商品。但「大宗商品」到轉錄為止。如果模型無法對它聽到的東西進行推理 —— 時序、說話者、情緒、音樂結構、環境聲 —— 光靠轉錄是撐不起產品功能的。

有三條顯而易見的路線：

1. 串接：Whisper 轉錄，LLM 對逐字稿推理。在純語音情境下可行。碰到音樂、環境音訊、多人重疊說話、情緒就失效。

2. 端到端音訊 LLM：一個音訊編碼器把音訊詞元直接餵進 LLM，跳過轉錄。保留了聲學資訊（情緒、說話者、環境）。需要新的訓練資料。

3. 混合式：音訊編碼器 + 一個既能轉錄又能推理的文字解碼器。Qwen-Audio 與 Audio Flamingo 走的就是這條路。

## 核心概念

### 對數梅爾頻譜圖：輸入特徵

每個音訊編碼器都從同一個特徵起步：對數梅爾頻譜圖。

1. 重取樣到 16 kHz。
2. 用 25ms 的窗、10ms 的跳距做短時傅立葉變換。
3. 取 FFT 結果的幅值。
4. 套用梅爾濾波器組（通常是 80 個在 0 到 8000 Hz 之間對數分布的濾波器），把頻率彎折到感知尺度。
5. 做對數壓縮（log(1 + x)）以壓縮動態範圍。

結果：一個形狀為 (T, 80) 的二維陣列，其中 T 是時間畫格數。以一段 30 秒、畫格率 100 Hz 的片段而言：(3000, 80)。

### Whisper 的編碼器

Whisper 的編碼器是一個 12 層的 ViT 風格 Transformer，把對數梅爾頻譜圖當成一串時間畫格來處理。輸出：每個時間畫格一個隱藏狀態向量。

做 ASR 時，Whisper 的解碼器是一個交叉注意力 Transformer，以編碼器輸出為條件生成文字詞元。標準的編碼器—解碼器。

做 ALM（音訊 LLM）時，你要的是把編碼器輸出當成另一個 LLM 的輸入。模式是：Whisper 編碼器凍結，Q-former 可訓練，LLM 凍結或微調。

### BEATs 與音訊專屬的編碼器

Whisper 是在以語音為主的資料上訓練的。它在音樂與環境音訊上較弱。

BEATs（Chen 等人，2022）是一個在 AudioSet 上訓練的自監督 Transformer。在相同參數量下，它捕捉音樂與環境聲的能力勝過 Whisper。

AF-Whisper（Audio Flamingo 3 的混合體）：把 Whisper 與 BEATs 的特徵串接起來當作音訊輸入。Whisper 承載語言訊號，BEATs 承載聲學訊號。

### 音訊 Q-former

與 BLIP-2 的視覺 Q-former 是同一套模式。固定數量的可學習 query（常見是 32 或 64 個）去交叉關注音訊編碼器輸出的那些畫格。這些 query 就成了供 LLM 取用的音訊詞元。

訓練的對齊階段：只訓練 Q-former，在音訊—文字配對（AudioCaps、Clotho）上跑對比與字幕損失。指令階段：端到端，解凍 LLM，在指令資料上訓練。

### 這條弧線 —— SALMONN、Qwen-Audio、AF3

SALMONN（Tang 等人，2023）：Whisper + BEATs + Q-former + LLaMA。第一個具備認真推理能力的開放音訊 LLM。在 MMAU 上的基準綜合分數約 0.55。

Qwen-Audio（Chu 等人，2023）：架構類似，在更豐富的資料集上訓練，並為多輪對話調校。MMAU 約 0.60。

LTU —— Listen, Think, Understand（Gong 等人，2023）：明確的推理資料，聚焦在音訊片段上的思維鏈。規模較小但更聚焦。

Audio Flamingo 3（Goel 等人，2025 年 7 月）：當前的開放 SOTA。8B 的 LLM 骨幹（Qwen2 7B）、Whisper-large 編碼器串接 BEATs、64 query 的 Q-former，在 100 萬組以上的音訊—文字指令配對上訓練。MMAU 0.72，在部分子任務上追平專有的前沿模型。

AF3 還引入了音訊上的隨選思維鏈：模型可以選擇在最終答案之前先吐出思考詞元（「我先來辨識一下樂器：……」）。啟用思考時，複雜推理任務的準確率會提升 3 到 5 分。

### 串接式對端到端

串接式管線：

1. Whisper 把音訊轉錄成文字。
2. LLM 對文字推理。

用來「摘要這集 podcast」完美無缺。但碰到這些就失效：
- 「這首歌的情緒是什麼？」—— 情緒在聲音裡，不在文字裡。
- 「說話的是 Alice 還是 Bob？」—— 這需要說話者辨識。
- 「爆炸發生在第幾秒？」—— 時間接地在轉成文字時就流失了。
- 「這是真實還是生成的音訊？」—— 深偽偵測需要聲學特徵。

端到端保留了聲學訊號。Qwen-Audio 與 AF3 原生就能處理音樂、環境與情緒。

### 2026 年的生產配方

要做一個新的音訊理解產品：

- 選串接式，如果：轉錄就是目的，沒有音樂，也不必推論情緒。
- 選 AF3／Qwen-Audio 家族，如果：有音樂、情緒、多說話者，或複雜的音訊推理。

串接式更便宜也更簡單。端到端則能力更強。

### MMAU —— 音訊推理的基準

MMAU（Massive Multimodal Audio Understanding）是 2024 到 2025 年的音訊推理基準：

- 10,000 組橫跨語音、音樂、環境聲的音訊—文字問答配對。
- 涵蓋分類、時間推理、因果推理與開放式問答。
- 測的正是串接式管線系統性會漏掉的東西。

開放的 SOTA（AF3）是 0.72；專有的前沿約 0.78（Gemini 2.5 Pro、Claude Opus 4.7）。這道落差比 VideoMME 上開放對封閉的差距小，顯示音訊 LLM 正在成熟。

## 框架應用

`code/main.py`：

- 用 stdlib 實作對數梅爾頻譜圖的計算：加窗、樸素 DFT、梅爾濾波器組。
- 音訊 Q-former 的骨架：給定編碼器輸出的畫格，算出 Q、K、V 與注意力，並吐出 N 個詞元。
- 在一項玩具任務上做串接式與端到端的比較。

## 產出交付

這一課產出 `outputs/skill-audio-llm-pipeline-picker.md`。給定一項音訊任務（轉錄、音樂標記、情緒推論、多說話者分段標記、環境分類），它會在串接式、端到端的 AF3 或混合式之間做出選擇。

## 練習

1. 算出一段 30 秒、16kHz、25ms 窗、10ms 跳距、80 個梅爾頻帶的片段，其對數梅爾頻譜圖的維度。換成 48kHz 會怎麼變？

2. Whisper 為什麼在音樂上表現不佳？BEATs 捕捉到哪些 Whisper 沒捕捉到的音訊特徵？

3. 64 query 的音訊 Q-former 對上 32 query：任務複雜到什麼程度，64 才划算？32 又替什麼省下了計算？

4. 讀 AF3 第 4 節關於隨選思考的部分。提出三項思維鏈幫助最大的音訊任務。

5. 用 AF3 的輸出實作一條最小的說話者分段標記管線。你要怎麼標示說話者的切換？

## 關鍵術語

| 術語 | 大家怎麼說 | 實際上是什麼 |
|------|-----------------|------------------------|
| 對數梅爾頻譜圖 | 「梅爾特徵」 | 經梅爾濾波器組之後，由對數幅值構成的二維（時間, 頻率）陣列 |
| 音訊 Q-former | 「音訊版 Perceiver」 | 從音訊編碼器輸出到固定長度 query 的交叉注意力瓶頸，其輸出餵給 LLM |
| 串接式 | 「先 ASR 再 LLM」 | 由 Whisper 轉錄、文字 LLM 推理的管線；會流失聲學資訊 |
| 端到端 | 「音訊 LLM」 | 音訊特徵透過 Q-former 直接進入 LLM；保留聲學訊號 |
| BEATs | 「AudioSet 音訊編碼器」 | 在 AudioSet 上訓練的自監督 Transformer；在音樂 + 環境聲上很強 |
| MMAU | 「音訊推理基準」 | 橫跨語音、音樂、環境的 1 萬組問答配對；2024 年的評測標準 |
| 隨選思考 | 「音訊 CoT」 | 模型可選擇在最終答案之前吐出推理詞元，準確率提升 3 到 5 分 |
